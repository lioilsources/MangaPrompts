## Purpose

Flutter app for building AI image generation prompts in LEGO-style cross-matrix
format. Users select blocks (head style, manga style, historical style) to
compose complete Grok Image prompts. Web ships as a Telegram Mini App backed by
`tgbot/` (FastAPI + aiogram on JODA → ComfyUI on SPARK).

## Build and test

```bash
flutter pub get
flutter analyze --no-fatal-infos   # CI gate
flutter test                       # CI gate
flutter run -d chrome              # web; also -d macos
cd tgbot && venv/bin/python -m pytest tests/ -q   # bot tests (tgbot/README.md)
```

## Map

```
lib/
├── main.dart, app.dart
├── config/      # block loader, restyle styles, hairstyle catalog (generated), models/
├── platform/    # Telegram WebApp seam (conditional imports)
├── providers/   # Riverpod state (flutter_riverpod + riverpod_generator)
├── services/    # prompt engine, image backends (ComfyUI, xAI, ol1n, Telegram)
└── ui/          # screens/, widgets/
assets/config/blocks/*.yaml   # prompt block axes
assets/comfyui/*.api.json     # ComfyUI workflows
tgbot/                        # Telegram bot + Mini App API, bench in tools/bench/
comfyui_nodes/                # our ComfyUI nodes (ComfyUI-Tsumiki), deploy.sh
```

## Invariants

- Web generation goes only through `tgbot/`, never through the direct
  xAI/ol1n/ComfyUI clients.
- Anything importing dart:io/cronet_http/gal/path_provider stays out of the web
  import graph (conditional imports in `backend_factory.dart`, `image_service.dart`,
  `repose_entry.dart`, `local_image.dart`, `platform/telegram_webapp.dart`).
- Web deploys ONLY from CI (`.github/workflows/deploy-web.yml`); local
  `lib/config/secrets.dart` may hold skip-worktree creds a local deploy would leak.
- `medium` is the only axis that declares photo vs. drawn; `style` carries no
  render-medium words. Conflicts via `incompatible:`, no "requires" relation.
- Each template's `workflow:` matches its prompt language; model auto-selection
  is never silent. Workflows are registered twice (`WORKFLOW_FILES` in
  `tgbot/config.py`, `ComfyWorkflow` in `comfy_image_service.dart`).
- A new graph passes `tgbot/tools/check_workflow.py` against SPARK first;
  `comfyui_nodes/deploy.sh` runs before a graph using our nodes ships
  (Ol1nLLM sends the same graphs).
- The hairstyle catalog (`lib/config/hairstyle_catalog.dart`), previews and
  swatches are generated by `export_catalog.py`; do not edit by hand.
- Synthetic portraits only, no personal data, no stock photos.
